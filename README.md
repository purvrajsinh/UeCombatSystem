# Unreal Engine C++ Combat System

A modular and scalable **Combat System developed in Unreal Engine using C++**, featuring character states, scalable weapons, destructible objects, multiple enemy types, smart enemy AI, and Motion Warping.

## 🎮 Features

- **Character State System**
  - Manages different character movement and combat states.
  - Designed to be easily extended with additional states.

- **Scalable Weapon System**
  - Modular weapon architecture using C++.
  - Supports different weapon types and attack behaviors.
  - Designed for easy addition of new weapons.

- **Destructible Objects**
  - Interactive destructible objects and environments.
  - Objects respond dynamically to combat interactions.

- **Modular Enemy System**
  - Multiple enemy types derived from a common **Base Enemy class**.
  - Shared functionality with support for unique enemy behaviors.

- **Smart Enemy AI**
  - Enemies can make combat decisions and engage the player dynamically.
  - Supports multiple attack patterns.

- **Multiple Enemy Attacks**
  - Different attacks and attack animations.
  - Designed to support additional attacks and abilities.

- **Motion Warping**
  - Used Motion Warping to dynamically align enemies with the player during attacks.
  - Helps create more accurate and responsive combat animations.

## 🛠️ Technologies

- **Unreal Engine**
- **C++**
